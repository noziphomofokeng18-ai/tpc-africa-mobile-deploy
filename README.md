# 📱 TPC Africa Mobile - Interactive Business Page

This is a static HTML page explaining the TPC Africa Mobile business model.

## How to Deploy (Choose One)

### Option 1: Vercel (Recommended)
```bash
npm install -g vercel
vercel --prod
```

### Option 2: Netlify
```bash
npm install -g netlify-cli
netlify deploy --prod
```

### Option 3: GitHub Pages
1. Enable GitHub Pages in repository settings
2. Set source to `main` branch
3. Your site will be live at: https://yourusername.github.io/tpc-africa-mobile-deploy
